## 검증 범위

정적 검사와 빌드 단계 자동 검증을 넣었지만, 최종 IPA의 실제 iPad 화면 렌더링과 스피커 음정은 실제 기기 설치 후 마지막으로 확인해야 합니다.

## 4음 연속 음자리표 고정
- `둘 다`를 선택해도 한 세트의 4개 음은 동일한 음자리표를 사용합니다.
- 음자리표 랜덤 선택은 새 4음 세트가 시작될 때만 1회 수행됩니다.
- 세트 진행 중 1→2→3→4번째 음 전환에서는 음자리표가 바뀌지 않습니다.

## 실기 피드백 반영 수정
- 단음 모드: 긴 오선을 줄이고 중앙 배치
- 화면 피아노: 전체 좌표 기반 터치 판정 + 검은건반 우선 판정
- 판정: PERFECT/GREAT/GOOD/OK/MISS를 동일하게 크게 표시
- 전체 난이도: C2~C6 전체 범위를 유지하면서 음자리표별 실제 기보 범위로 배분
- MISS: 한 번 틀리면 해당 음의 결과를 MISS로 확정하고 정답을 찾아야 다음으로 진행
- 판정/문제 전환: 다음 음은 빠르게 제시하고 판정은 약 0.65초 유지
- 4음 연속: 한 세트 4음의 음자리표 고정 유지
