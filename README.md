# 초견 트레이너 v1.0 — 초견 모드 4차 렌더링 조정

이번 테스트본은 기존 한손/양손/화음 모드를 유지하면서 1ère Gymnopédie 초견 모드의 악보 표현을 조정한 버전입니다.

주요 변경:
- 첫 마디의 음자리표/조표/박자표/셈여림 겹침을 피하도록 시작 공간 확대
- 현재 위치 커서를 실제 음표 영역 안으로 제한하여 악상기호를 가리지 않도록 수정
- 3/4의 3박 음표를 점2분음표로, 3박 쉼표를 온쉼표 기호로 구분
- VexFlow 성부 포맷팅에서 상/하 보표의 불필요한 충돌 결합 제거
- 음표 기둥 길이를 제한하여 비정상적으로 길게 보이는 현상 완화
- 5마디 × 2단 표시와 검증된 78마디/188개 MIDI 판정 데이터 유지

아직 원본의 긴 프레이즈 슬러/헤어핀은 별도 렌더 이벤트로 완전 전사되지 않았습니다.
