# 초견 트레이너 v1.0 — 초견 모드 3차 (악보 렌더링 재구축)

- 1ère Gymnopédie 78마디 데이터 유지
- 초견 악보를 임의 SVG 문자 렌더러에서 **VexFlow 4.2.2 기반 피아노 대보표 렌더러**로 교체
- 원본 1.pdf 레이아웃에 맞춰 1단 5마디, 화면 2단(10마디) 표시
- 각 시스템 시작에서만 음자리표/조표 표시, 첫 시스템에서만 3/4 박자표 표시
- 대괄호/연결선, 음표·쉼표·점음표·임시표를 VexFlow 음악 기호로 렌더링
- 현재 MIDI 판정 위치는 실제 포맷된 음표 X좌표에 커서 표시
- 기존 한손/양손/화음 모드 로직은 변경하지 않음

※ 슬러/헤어핀은 현재 JSON에 렌더 이벤트가 없어 이번 단계에서는 제외. 음높이/리듬/쉼표/화음/붙임줄/임시표/보표 위치는 기존 검증 데이터 사용.
